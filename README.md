# Bem Lembrado — Apresentação

Apresentação acadêmica do projeto **Bem Lembrado**, uma proposta de apoio à rotina da pessoa idosa pelo WhatsApp, com acompanhamento de contatos autorizados.

## Como visualizar

Abra `apresentacao/index.html` em um navegador ou inicie um servidor local na pasta do projeto.

Durante a apresentação:

- setas, espaço ou Enter: avançar;
- setas para a esquerda ou Backspace: voltar;
- `F`: entrar ou sair da tela cheia;
- Home e End: ir ao primeiro ou ao último slide.

## Arquivos principais

- `apresentacao/index.html`: apresentação web com animações;
- `apresentacao/Bem_Lembrado_Apresentacao_FINAL.pdf`: versão final em PDF;
- `09_ROTEIRO_DE_FALA.md`: roteiro dividido entre quatro pessoas;
- `10_PERGUNTAS_E_RESPOSTAS.md`: preparação para perguntas;
- `11_PLANO_DE_ENSAIO.md`: plano de ensaio e checklist.

## Observação

O protótipo e os dados de funcionamento representam uma simulação da solução planejada para o MVP. A integração completa e a validação com usuários pertencem à etapa seguinte do projeto.
