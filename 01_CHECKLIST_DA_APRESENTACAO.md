# Checklist da apresentação

## Restrições obrigatórias

- [ ] O arquivo final está em PDF.
- [ ] A apresentação cabe em 7 a 10 minutos.
- [ ] O material está pronto para entrega até 19/10, às 23h59.
- [ ] Há um ensaio cronometrado.

## Conteúdo do projeto

- [ ] O projeto é identificado e apresentado com clareza.
- [ ] O contexto e o problema estão explicados.
- [ ] O público beneficiado está definido.
- [ ] O impacto social esperado está demonstrado.
- [ ] A proposta inicial da solução está sintetizada.
- [ ] A viabilidade do projeto está justificada.
- [ ] O escopo inicial está delimitado.
- [ ] Os stakeholders principais estão identificados.
- [ ] Os recursos necessários estão resumidos.
- [ ] Os requisitos funcionais estão contemplados.
- [ ] Os requisitos não funcionais estão contemplados.
- [ ] Os principais riscos incluem probabilidade e impacto.
- [ ] O cronograma apresenta atividades, tempo, recursos e dependências.
- [ ] A metodologia de gestão está explicada.

## Demonstração e fechamento

- [ ] O protótipo inicial aparece de forma visual e compreensível.
- [ ] A solução é demonstrada, e não apenas descrita.
- [ ] Os resultados alcançados são apresentados com evidências disponíveis.
- [ ] Os desafios são explicados de forma objetiva.
- [ ] Os aprendizados estão sintetizados.
- [ ] O cronograma da segunda etapa é mostrado.
- [ ] O encerramento reforça o valor e o impacto do projeto.

## Pontos a confirmar durante a preparação

- [ ] Quantidade de integrantes e divisão das falas.
- [ ] Equipamento e modo de exibição no dia.
- [ ] Critério visual ou modelo institucional, se existir.
- [ ] Necessidade de referências bibliográficas no PDF.
